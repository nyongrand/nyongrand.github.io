Kebijakan Privasi Nutripas

Terakhir diperbarui: 3 Oktober 2026.

Kebijakan ini menjelaskan pengelolaan data dalam aplikasi Nutripas: Kalkulator Nutrisi, termasuk kalkulator gizi, pemantauan pertumbuhan anak (KMS), artikel, dan konsultasi melalui chat. Untuk pertanyaan atau permintaan terkait data pribadi, hubungi pengelola Nutripas melalui WhatsApp +62 858-1993-5078.

Data akun dan notifikasi

Saat Anda masuk menggunakan Google, aplikasi menggunakan identitas akun Google melalui Firebase Authentication, termasuk ID pengguna, alamat email, nama, dan foto profil yang tersedia. Nutripas tidak meminta atau menyimpan kata sandi akun Google Anda.

Saat melengkapi registrasi, Anda memberikan nama, tanggal lahir, jenis kelamin, dan nomor telepon opsional. Profil tersebut disimpan di Cloud Firestore untuk identifikasi pengguna dan layanan konsultasi. Tanggal lahir dan jenis kelamin mendukung informasi usia dan kebutuhan gizi. Aplikasi juga menyimpan token Firebase Cloud Messaging pada profil untuk mengirim notifikasi. Izin notifikasi dapat ditolak atau diubah melalui pengaturan Android.

Konsultasi dan artikel

Pesan yang Anda kirim melalui chat, identitas pengirim, waktu pesan, dan informasi percakapan disimpan di Firebase Realtime Database untuk menyediakan riwayat dan konsultasi. Admin layanan dapat mengakses percakapan untuk memberikan tanggapan. Pesan dapat memuat informasi kesehatan yang Anda pilih untuk bagikan; hindari mengirim data yang tidak diperlukan untuk konsultasi.

Artikel yang dipublikasikan melalui aplikasi, termasuk judul dan isinya, disimpan melalui Firebase dan dapat dibaca pengguna aplikasi. Jangan memasukkan informasi pribadi yang tidak dimaksudkan untuk dipublikasikan ke dalam artikel.

Kalkulator dan data KMS

Input kalkulator gizi diproses di perangkat untuk menghasilkan perhitungan. Nama anak, tanggal lahir, jenis kelamin, serta catatan berat dan panjang atau tinggi badan KMS disimpan dalam database Room di perangkat. Alur KMS saat ini tidak mengunggah catatan tersebut ke database Firebase.

Android dapat mencadangkan atau memindahkan data aplikasi, termasuk database lokal, sesuai pengaturan perangkat dan layanan pencadangan Anda. Menghapus data aplikasi atau menghapus instalasi dapat menghapus salinan lokal; salinan cadangan dan pemulihan mengikuti pengaturan layanan pencadangan. Logout tidak menghapus akun, percakapan di server, atau seluruh data KMS lokal.

Layanan Google dan data teknis

Nutripas menggunakan layanan pihak ketiga berikut:

  • Firebase Authentication, Cloud Firestore, Realtime Database, dan Storage untuk autentikasi, profil, percakapan, konten, dan pemuatan gambar.
  • Firebase Cloud Messaging untuk pengiriman notifikasi.
  • Google Analytics for Firebase untuk statistik penggunaan dan interaksi aplikasi.
  • Firebase Crashlytics untuk laporan crash dan diagnosis gangguan. ID pengguna dapat dikaitkan dengan laporan agar gangguan pada sesi pengguna dapat ditelusuri.
  • Google AdMob untuk menampilkan banner dan iklan berhadiah yang digunakan dalam akses konsultasi.

SDK tersebut dapat memproses data teknis seperti alamat IP, pengenal perangkat atau instalasi, ID iklan jika tersedia, informasi perangkat dan sistem operasi, interaksi aplikasi atau iklan, serta laporan gangguan sesuai layanan dan konfigurasinya. Data digunakan untuk menyediakan layanan, statistik, diagnosis, penayangan dan pengukuran iklan, serta pencegahan penyalahgunaan. Penanganan oleh penyedia layanan dijelaskan dalam Kebijakan Privasi Google dan Privasi dan Keamanan Firebase.

Penyimpanan dan keamanan

Data akun dan percakapan disimpan pada layanan Firebase untuk menyediakan fungsi aplikasi; data KMS disimpan secara lokal seperti dijelaskan di atas. Lama penyimpanan dapat berbeda menurut jenis data, kebutuhan layanan, serta ketentuan penyedia layanan. Hubungi pengelola untuk informasi atau permintaan terkait penyimpanan dan penghapusan data Anda.

Komunikasi aplikasi dengan endpoint Firebase menggunakan koneksi HTTPS. Kebijakan ini tidak menjanjikan bahwa seluruh pesan terenkripsi ujung ke ujung atau bahwa setiap sistem kebal terhadap gangguan dan akses tidak sah. Jangan membagikan kata sandi, kode masuk, atau data sensitif yang tidak diperlukan melalui chat.

Pilihan dan permintaan terkait data

Anda dapat menggunakan fitur yang tidak memerlukan login tanpa membuat akun konsultasi, memilih untuk tidak mengisi nomor telepon opsional, mengatur izin notifikasi, serta mengatur privasi iklan dan pencadangan melalui pengaturan perangkat yang tersedia. Pembatasan izin atau layanan dapat memengaruhi fitur terkait.

Untuk pertanyaan, koreksi, atau permintaan penghapusan data, hubungi WhatsApp pengelola Nutripas. Pengelola dapat meminta informasi yang diperlukan untuk memverifikasi kepemilikan akun. Jangan mengirim kata sandi atau kode verifikasi. Permintaan melalui kontak ini tidak berarti penghapusan otomatis, dan logout bukan penghapusan akun.

Perubahan kebijakan

Kebijakan dapat diperbarui ketika fitur atau pengelolaan data berubah. Versi yang diperbarui akan mencantumkan tanggal pembaruan dan tersedia melalui halaman Kebijakan Privasi Nutripas. Tinjau kembali halaman ini untuk mengetahui informasi terbaru.
